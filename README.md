# 🕸️ Quotes Web Scraper

A Python-based web scraping project that extracts quotes, authors, and tags from a website and stores the data in an Excel file using Pandas.

## 📌 Project Overview

This project scrapes quotes from a website and saves the extracted data into an Excel file with the following columns:

- Quote
- Author
- Tags

The project uses:

- **Requests** → To fetch webpage content
- **BeautifulSoup** → To parse HTML data
- **Pandas** → To store data in Excel format

---

## 🚀 Features

✔ Scrapes quotes from a website  
✔ Extracts author names  
✔ Extracts tags for each quote  
✔ Stores data in structured Excel format  
✔ Easy to modify for other websites  

---

## 🛠️ Technologies Used

- Python 3
- Requests
- BeautifulSoup4
- Pandas
- OpenPyXL
